# Mi Menú Eileen

Web estática para Vercel. Fotografías recortadas del material aportado por el usuario; son orientativas y no sustituyen los ingredientes escritos. Domingo libre.

## Publicación

Subir todos los archivos de esta carpeta a la raíz del repositorio GitHub. Vercel: Framework Other, sin build, output `.`.

## Datos

La planificación y las marcas de compra se guardan en localStorage del navegador. Hay opción de exportar e importar copia desde Compra.

## Nota

Las cantidades con alternativas `O` no se suman automáticamente. Verifica las cantidades antes de comprar.
